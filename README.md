## ✨ Features

- Sticky frosted-glass navigation bar with `backdrop-filter: blur()`
- Featured hero post with author info and read time
- Horizontal post cards with thumbnails, categories and excerpts
- Filter buttons (All / Design / Tech / Business)
- Newsletter signup widget in sidebar
- Popular posts sidebar with read counts
- Browse topics tag cloud
- Pagination controls
- Multi-column footer with social links
- Fully responsive across all screen sizes (1024px / 768px / 560px)
- Zero JavaScript dependencies — pure CSS interactions

---

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Semantic structure (`<nav>`, `<main>`, `<aside>`, `<footer>`) |
| CSS3 | Grid, Flexbox, Variables, `clamp()`, `backdrop-filter` |
| JavaScript | Filter button interactions |
| Google Fonts | Libre Baskerville + IBM Plex Sans |

---

## 🧠 CSS Concepts Used

- CSS Custom Properties (variables)
- CSS Grid — featured layout, main+sidebar, footer
- Flexbox — nav, post meta, pagination
- `clamp()` — fluid responsive typography
- `backdrop-filter: blur()` — frosted glass nav effect
- `-webkit-line-clamp` — 2-line text truncation on excerpts
- `position: sticky` — navbar stays on scroll
- `scroll-behavior: smooth` — smooth anchor navigation
- Linear gradients — placeholder image backgrounds
- CSS transitions — hover effects on links and buttons

---

## 📱 Responsive Breakpoints

| Breakpoint | Layout Change |
|---|---|
| `≤ 1024px` | Sidebar moves below main content |
| `≤ 768px` | Featured section stacks, post cards go single column |
| `≤ 560px` | Nav links hidden, footer goes single column |
